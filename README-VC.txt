- Run _get-libs-vc.bat
	- This will automatically download and setup the libraries.
	- DO NOT EXECUTE IN A FOLDER WHERE ADMINISTRATOR ACCESS IS REQUIRED.
		- Run in User folder (Desktop, My Documents etc...)

- Open DDWolf.VC2026.sln
	- DDWolf.VC2022.sln or DDWolf.VC2019.sln if you have older IDE.

- In the toolbar, make sure you are set on 'Release' (not 'Debug')

- Select your platform (x86 or x64)

- Compile
