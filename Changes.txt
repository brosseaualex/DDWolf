DDWolf v1.4.0 (xxx XX, 2026)
 [Added]
	- New engine variant - DDWolf-Legacy*.
		- SDL1 has been re-implemented.
			- Requires SDL-1.2.15 & SDL_mixer-1.2.12
			- This reinstates support for Windows 95, 98, ME, NT, 2000.
			- Windows XP is compatible with both SDL1 and SDL2.
			- Every other Windows version after XP requires SDL2.
		- Modernized SDL1 implementation.
			- Everything should work almost the exact same as the SDL2
			version, within SDL1's limitations.
			- Aspect ratio is kept in fullscreen.
		- Lost features
			- No borderless fullscreen in SDL1.
			- No VSync in SDL1 for 2D surfaces.
				- Replaced with "Double Buffering".
		- DDWolf-Legacy_x86.VC2026.sln (Visual Studio 2026)
		- DDWolf-Legacy_x86.cbp (CodeBlocks + MingW x86)
	- Added back some older command line args and some new ones.
		- '--res <width> <height>'
		- '--forcewindowed'
		- '--novsync' - SDL2 only
		- '--nodblbuf' - Legacy only (SDL1)
		- '--extravbls <vbls>'
	- When Overhead map is enabled, you can now rebind the key.

 [Fixed]
	- Fixed rendering issue with rain/snow and textured ceiling.
	- Fixed issue in resolution menu where not all resolution
	would be assigned an aspect ratio.
	- Fixed a crash when going on the ReadThis without an actual file.
		- Now it just goes back to main menu.

*DDWolf-Legacy is provided 'as-is' and no support will be provided other than bug fixes*

DDWolf v1.3.1 (Sep 16, 2026)
 [Added]
	- Two additional feature flags tiles.
		- The two tiles to the left of the upper right corner of each level.
			- Gives a total of 3 feature flags.
			- This is to enable easy combination of different flags.
				- Ex: Clouds & Rain
			- Flags will not "cumulate" if you put the same flag multiple times.
				- They are applied only once.
			- Some flags might not render well together.
	- Visual Studio 2026 Solution.
	
 [Changed]
	- Default resolution when starting the game for the
	first time set to 320x200 instead of monitor resolution.
	- Default viewsize is back at 19.
		- The game now looks exactly like it did during
		the DOS days the first time you launch it.
	
 [Fixed]
	- Fixed shade table issue when loading a save from another level.

DDWolf v1.3.0 (Sep 13, 2026)
 [Added]
	- Display resolution & options menu
		- Can now change the resolution directly in game.
		- Resolution change keeps aspect ratio in every display mode.
		- Enable/Disable Fullscreen (exclusive & windowed mode).
		- Enable/Disable VSync
	- Atmosphere options menu
		- Meant to be used by mod makers if they use certain feature flags
			and want to allow players to have control over the options.
				- Enable/Disable Textured floors & ceilings.
				- Enable/Disable Shading.
				- Enable/Disable Skybox (clouds, sky, etc...).
				- Enable/Disable Precipitation (rain, snow).

 [Changed]
	- Improved scaling of Star Sky.
	- Mouse input is now always grabbed when starting game.
		- Mouse input was specifically not taken when starting game in windowed mode.
			- Not an issue anymore since alt-tabbing issues are resolved.
				- Press SCROLL LOCK or F12 to release/grab mouse in game.

 [Fixed]
	- Fixed distant sound issue in VIEASM.
	- Fixed scaling issues with Rain/Snow at higher resolutions.
	- Fixed scaling issues on a few screens (intermission & end game).
	- Fixed leaking rain/snow through ceilings.
	- Fixed some compilation issues when using certain flags.
	- Fixed alt-tabbing out of game.
		- Game would fight (and win) for focus when trying to alt-tab.
			- The game lost.

 [Removed]
	- Removed support for Spanish and Japanese language.
		- I am unable to maintain those languages.
			This is just dead code so I have decided to remove it.
		- If anyone ever wants to support a translation, in any language,
			I will be happy to help re-implementing what is required for it :)
	- Removed a few command line arguments that are now redundant/useless.
		- 'doubleBuffering' - Old remnants of SDL1, SDL2 has double buffering,
			you cannot even turn it off.
		- 'extravbls' - Old remnants of SDL1, seems to have been used in
			case where VSync would help. SDL2 has VSync, you can turn in
			ON/OFF in Display menu.
		- '--windowed'
		- '--res'
		- '--resx'
		- '--disableratiofix'
		- '--disablehdres'
			- These settings can now be changed in the game menu and if
				your settings ever break, delete config.wl6 and restart the game.
